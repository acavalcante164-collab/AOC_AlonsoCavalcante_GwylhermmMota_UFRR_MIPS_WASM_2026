# AOC_AlonsoCavalcante_UFRR_MIPS_WASM_2026

---

Este relatório apresenta a implementação e simulação de aritmética MIPS para WebAssembly. O projeto tem como foco, descer ao nível dos bits em C, garantir que o código seja seguro contra falhas críticas usando Verificação Formal de Software (Map2Check), compilar esse código para uma máquina virtual de pilha (WASM) e, finalmente, construir uma visualização gráfica que anima o fluxo aritmético passo a passo além da aplicação rigorosa de  tudo que aprendermos até o momento na disciplina.
